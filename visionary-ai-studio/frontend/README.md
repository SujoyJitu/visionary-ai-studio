# Visionary AI Studio: Frontend

React + Vite + Tailwind CSS v4 + Framer Motion + Lucide.

## Run it

Requires Node.js 18+ (20 recommended).

```bash
npm install
npm run dev
```

Open http://localhost:5173

## What's built

- Landing page: Navbar, Hero (interactive sample analysis), Features, How it works, Footer
- Routing with react-router-dom (`/login` and `/register` are placeholders)
